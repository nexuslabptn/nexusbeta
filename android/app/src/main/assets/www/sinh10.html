Nhấp chuột bất kỳ để thả tinh trùng X hoặc Y bơi hướng thẳng vào tế bào trứng

NHẤP ĐỂ THẢ TINH TRÙNG
Trạng thái: Nhấp chuột để phóng tinh trùng vào noãn Đã thụ tinh: 0 lần
Nhấp bất kỳ để phóng tinh trùng
Tỉ lệ Đực : Cái ≈ 1 : 1 (50% : 50%)

Thống Kê Giới Tính

0
Bé Gái (XX)
0
Bé Trai (XY)

Cơ chế xác định giới tính:

• Trứng luôn mang 1 NST X.
• Tinh trùng gồm 50% mang X và 50% mang Y.
• Khi thụ tinh: Trứng (X) + Tinh trùng (X) → Hợp tử XX (Gái); Trứng (X) + Tinh trùng (Y) → Hợp tử XY (Trai).
